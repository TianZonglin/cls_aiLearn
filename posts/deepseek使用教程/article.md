# DeepSeek 使用教程：从安装到实战，一篇带你玩转 Harness

最近 AI 圈最火的话题，莫过于 DeepSeek 官宣的 Harness 项目。GitHub 上 Star 数一路飙升，已经突破 109k。很多人还不清楚它到底是什么，简单说：**Agent = Model + Harness**——模型是大脑，Harness 就是身体。它让 AI 不再只是“聊天机器人”，而是能真正动手干活的智能体：读写文件、上网查资料、写代码、操作电脑，甚至自己造插件。

这篇文章不讲虚的，直接上实操。我将带你从零开始安装 DeepSeek Harness，配置环境，跑几个真实任务，看看它到底能干什么、效果如何、花多少钱。最后再分享一个换皮肤的插件玩法，让你的界面与众不同。

## 一、准备工作：只需要两样东西

开始之前，确保你准备好以下两样：

1. **Node.js**：去官网下载 LTS 版本，一路“下一步”装完即可。
2. **DeepSeek API Key**：到 DeepSeek 开放平台创建，记得充一点钱，API 是按量收费的。

如果你看不懂命令，别担心，遇到不懂的指令可以直接丢给任意 AI 工具，让它们帮你生成，两分钟就能搞定配置。

## 二、安装：两种方式任选

### 方式一：一行命令（推荐新手）

打开终端，输入：

```bash
npx @deepseek-ai/dsh web
```

### 方式二：从源码运行（进阶，方便自己改）

按顺序执行：

```bash
git clone https://github.com/deepseek-ai/deepseek-harness.git
cd deepseek-harness
pnpm install
pnpm run build
pnpm dsh web
```

两种方式跑完后，终端都会输出一个本地网址，一般是 `http://127.0.0.1:3080`。浏览器打开，第一次会要求填写 API Key，粘贴进去就进入首页，安装完成。

## 三、进去之后的四个设置

进入界面后，有四个设置点需要点几下：

1. 选择你希望 AI 操作的项目文件夹。
2. 配置模型参数（默认即可）。
3. 设置缓存策略（建议开启，省钱）。
4. 确认权限选项。

然后就可以开始干活了。

## 四、实测：四个不同类型的任务

为了验证 DeepSeek Harness 的能力，我让它干了四件事：做 PPT、做网站、分析项目，最后让它自己造插件。耗时、效果、花费全部如实记录。

### 任务 1：直接做一份 PPT（标准模式）

打工人最刚需的场景，这次用标准模式跑——能力最全的默认档，文件、网页、子任务全支持。

**提示词**：

```
帮我做一份 PPT，主题是「AI 工具入门」，面向完全没接触过 AI 的普通人。一共 10 页，结构如下：
第 1 页 封面：大标题 + 副标题「写给不想被时代抛下的你」+ 一句点题的话
第 2 页 目录：四个部分
第 3 页 为什么现在要学 AI 工具：不讲大道理，讲三个具体场景（写材料、做图、查资料）
第 4 页 最值得先学的 3 个工具：对话类、生图类、办公类各一个，每个一句话讲清楚干嘛用的
第 5 页 普通人怎么开始上手：三步走，第一周做什么、第一个月做什么
第 6 页 常见坑 1：别囤课，别收集一堆工具不用
第 7 页 常见坑 2：AI 会一本正经胡说八道，重要的事要核对
第 8 页 常见坑 3：别把隐私信息喂给 AI
第 9 页 一张「学习路径图」：从今天到三个月后的节奏
第 10 页 结尾：一句话总结 + 行动号召

视觉要求：整体风格简洁现代，每页一个大标题 + 3 到 5 条短要点，一页不要堆太多字；配色统一，标题色和强调色一致；封面要抓眼球，结尾页要有记忆点。用网页形式做出来（HTML 幻灯片，支持键盘翻页），做完了告诉我文件在哪、怎么打开，我先检查一遍版式和内容。
```

**过程与结果**：

10 页完整，没有缺页，结构完全按照提示词一步步来。版式和配色可以直接用，文字量控制得当，每页就几条要点。

- 耗时：3 分 34 秒（6 轮对话、11 步工具调用）
- 输入 149K、输出 20.4K token，缓存命中 73%
- 费用：按 V4-Flash 算，空闲时段约 1 毛 6，高峰时段约 3 毛 2

### 任务 2：做一个 AI 工具集合网站（PTC 模式）

难度上来一截，要真写代码、真出页面。这次特意切到 PTC 模式——它能让 AI 一次生成代码，把多步工具调用串起来，适合写网站这种步骤多但逻辑清晰的任务。

**提示词**：

```
帮我做一个「AI 工具集合」网站：
1) 按分类展示常用 AI 工具，比如对话、生图、生视频、编程
2) 每个工具一张卡片：名称、一句话简介、官网链接
3) 支持按分类筛选和关键词搜索
4) 界面好看，手机和电脑都能用
做完告诉我怎么打开，我先试一下。
```

**过程与结果**：

网站能直接打开，分类、搜索、筛选功能都是真实可用的，不是摆设。审美在线，响应式适配到位。

- 耗时：7 分 05 秒（1 轮对话、8 步工具调用，工具实际执行耗时 27 秒）
- 输入 318K、输出 41.4K token，缓存命中 83%
- 费用：空闲时段约 2 毛 8，高峰时段约 5 毛 6

### 任务 3：做项目分析（极简模式）

最难的一关，要真读代码、真做判断。这次用极简模式跑——它只留两个工具，官方说主要是拿来测模型的。我就想看看在这种“几乎裸奔”的环境下，AI 还能不能完成深度分析。

**提示词**：

```
工作区里有一个开源项目（D:\gitee\deepseek-harness，DeepSeek Harness 的源码）。帮我做一份项目分析报告：
1) 这个项目是干嘛的、解决什么问题
2) 整体架构和核心模块有哪些
3) 代码质量和设计思路怎么样
4) 它的优缺点，以及适合什么样的人用
输出成一份结构清晰的分析报告，存成新文件。
```

**过程与结果**：

结果完全超出预期。极简模式只有两个工具，居然产出了一份 222 行的完整分析报告，不是泛泛而谈：项目定位、Cordis 插件树架构、核心包、Turn/Step 运行流、事件溯源会话日志都讲到了，甚至还给出了代码质量评价和“适合谁用”的判断，连“不接受外部 PR”这种细节都挖出来了。

- 耗时：1 分 24 秒（1 轮对话、11 步工具调用）
- 输入 406K、输出 7.5K token，缓存命中 80%
- 费用：空闲时段约 1 毛 7，高峰时段约 3 毛 4

### 任务 4：让 AI 给自己造个插件（创造模式）

前三关都是“让 AI 干活”，这一关玩点不一样的：用创造模式让 AI 给自己造个工具。创造模式能检查系统里现在装着哪些插件、现场试验新插件，是 Harness「一切皆插件」理念最直接的体现。

**提示词**：

```
帮我在界面上做一个「余额悬浮窗」插件：实时显示 DeepSeek 账户剩余金额，跑任务时能看着钱一点点扣。写完先给我审批，没问题再装。
```

**过程与结果**：

插件正常装上，余额悬浮窗显示的数字和账户实际余额对得上，装完就能用。

- 耗时：6 分 48 秒（2 轮对话、15 步工具调用，工具执行 10 分 45 秒）
- 输入 1.2M、输出 44.5K token，缓存命中 89%
- 费用：空闲时段约 4 毛 5，高峰时段约 9 毛

## 六、插件玩法：换皮肤只需四步

Harness 主打「一切皆插件」，连操作界面都是插件，所以换皮肤这档子事特别简单。以安装一个 UI 插件合集为例：

**第一步**：安装 dsh 命令（已安装的忽略）

```bash
npm install -g @deepseek-ai/dsh
```

**第二步**：安装 UI 插件

```bash
dsh plugin --profile web add @linxin666/dsh-web-ui-all@0.1.12
```

**第三步**：重启网页生效

```bash
dsh web
```

**第四步**：刷新浏览器，打开设置，选择你喜欢的新皮肤。

## 总结

DeepSeek Harness 值不值得装？取决于你想干嘛。

- **会折腾的人**：这绝对是主力干活工具，PPT、网站、项目分析、插件开发全都能接，成本低到可以忽略。
- **不爱折腾的人**：装上也只会用标准模式，那它就是一个比普通聊天 AI 更能干的高级助手。

但无论你是哪类用户，有一点可以确定：在这个价位下，DeepSeek Harness 的“能干活”能力，市面上找不到第二个。趁价格还没涨太多，赶紧装上试试吧！
