# DeepSeek 使用教程：从零上手到进阶实战，一篇就够了

过去我们使用 AI，基本停留在“你问我答”的聊天层面。让它写个文案、翻译段话可以，但真要让它“自己动手干活”——做 PPT、写代码、搭网站、分析项目——它就无能为力了。

DeepSeek Harness 的出现，彻底改变了这个局面。

DeepSeek 官方用一句话概括了它的本质：**Agent = Model + Harness**。翻译成人话就是“AI 智能体 = 会思考的大脑 + 能干活的身体”。Harness 就是那个“身体”，让 AI 不再止步于聊天，而是真正具备了动手能力：读写文件、上网查资料、写代码、操作电脑，样样都行。

更关键的是，DeepSeek 把它开源了，发布后 GitHub 星标一路飙升，目前已超过 109k Star，还支持插件扩展，你可以在这套“工具箱”里自由拓展功能。

这篇文章不聊虚的理念，只讲实操。我会带你从环境准备、安装配置开始，再用四个真实任务（做 PPT、做网站、项目分析、自造插件）实测它的能力边界，记录完整的耗时和费用，看完你就能自己上手。

# 一、准备工作：只需要两样东西

在开始之前，你需要准备好两样东西：

1. **Node.js**：去官网下载 LTS 版本，一路下一步装完即可。
2. **DeepSeek API Key**：到 DeepSeek 开放平台创建，记得充点钱，API 按量收费。

如果你看不懂命令行操作，完全不用担心。安装过程中遇到不懂的命令，可以让任意 AI 工具帮你生成对应指令，两分钟就能完成配置。

# 二、安装教程：两种方式任选

## 方式一：一行命令安装（推荐新手）

打开终端，输入下面这条命令：

```bash
npx @deepseek-ai/dsh web
```

系统会自动拉取依赖并启动服务，非常简单。

## 方式二：从源码运行（适合想改代码的进阶玩家）

依次执行以下命令：

```bash
git clone https://github.com/deepseek-ai/deepseek-harness.git
cd deepseek-harness
pnpm install
pnpm run build
pnpm dsh web
```

两种方式跑完之后，终端都会输出一个本地网址，一般是 `http://127.0.0.1:3080`。用浏览器打开，第一次进入会要求填写 API Key，粘贴进去就进入首页，**安装完成**。

# 三、进去之后，先做四个设置

进入 DeepSeek Harness 界面后，建议先把下面几个设置搞定：

1. 选择默认模型（推荐 V4-Flash，性价比高）
2. 设置工作目录（选一个你想让 AI 操作的项目文件夹）
3. 确认工具权限（文件读写、网络访问等）
4. 调整 Token 缓存策略（提升速度、降低成本）

设置完成后，就可以正式开始干活了。

# 四、四种核心模式，分别怎么用？

DeepSeek Harness 提供了四种模式，对应不同任务场景。选择正确的模式，事半功倍。

| 模式 | 适用场景 | 特点 |
|------|---------|------|
| **标准模式** | 内容创作、文档生成、日常任务 | 能力最全，默认档位 |
| **PTC 模式** | 写代码、搭网站等步骤清晰的任务 | 一次生成代码，串联多步工具调用 |
| **极简模式** | 深度分析、模型能力测试 | 只保留两个核心工具，考验模型“裸奔”能力 |
| **创造模式** | 开发插件、扩展新功能 | 可检查系统现有插件、现场试验新插件 |

下面通过四个真实测试任务，让你直观感受每种模式的实战表现。

# 五、实测：四个任务，从 PPT 到自造插件

## 任务 1：直接做一份 PPT（标准模式）

打工人最刚需的场景，先用标准模式热身。给 AI 一份主题和要点，让它直接产出能用的 PPT，而不是只给建议。

**提示词：**

```
帮我做一份 PPT，主题是「AI 工具入门」，面向完全没接触过 AI 的普通人。一共 10 页，结构如下：
第 1 页 封面：大标题 + 副标题「写给不想被时代抛下的你」+ 一句点题的话
第 2 页 目录：四个部分
第 3 页 为什么现在要学 AI 工具：不讲大道理，讲三个具体场景（写材料、做图、查资料）
第 4 页 最值得先学的 3 个工具：对话类、生图类、办公类各一个，每个一句话讲清楚干嘛用的
第 5 页 普通人怎么开始上手：三步走，第一周做什么、第一个月做什么
第 6 页 常见坑 1：别囤课，别收集一堆工具不用
第 7 页 常见坑 2：AI 会一本正经胡说八道，重要的事要核对
第 8 页 常见坑 3：别把隐私信息喂给 AI
第 9 页 一张「学习路径图」：从今天到三个月后的节奏
第 10 页 结尾：一句话总结 + 行动号召
视觉要求：整体风格简洁现代，每页一个大标题 + 3 到 5 条短要点，一页不要堆太多字；配色统一，标题色和强调色一致；封面要抓眼球，结尾页要有记忆点。用网页形式做出来（HTML 幻灯片，支持键盘翻页），做完了告诉我文件在哪、怎么打开，我先检查一遍版式和内容。
```

**结果：** 10 页完整，无缺页，结构完全按提示词一步步来。版式和配色可以直接使用，文字量控制得当。耗时 3 分 34 秒（6 轮对话、11 步工具调用），输入 149K、输出 20.4K token，缓存命中 73%。费用按 V4-Flash 计算，空闲时段约 1 毛 6，高峰时段约 3 毛 2。

## 任务 2：做一个 AI 工具集合网站（PTC 模式）

难度升级，要真写代码、真出页面。这次用 PTC 模式，让 AI 一次生成代码，把多步工具调用串起来。

**提示词：**

```
帮我做一个「AI 工具集合」网站：
1) 按分类展示常用 AI 工具，比如对话、生图、生视频、编程
2) 每个工具一张卡片：名称、一句话简介、官网链接
3) 支持按分类筛选和关键词搜索
4) 界面好看，手机和电脑都能用
做完告诉我怎么打开，我先试一下。
```

**结果：** 网站做出来非常能打：分类、搜索、筛选功能全部真实可用，不是摆设。审美在线，响应式适配到位。耗时 7 分 05 秒（1 轮对话、8 步工具调用，工具实际执行耗时 27 秒），输入 318K、输出 41.4K token，缓存命中 83%，首 token 平均 2 秒，生成速度 101 tok/s。费用按 V4-Flash 计算，空闲时段约 2 毛 8，高峰时段约 5 毛 6。

## 任务 3：做项目分析（极简模式）

最难的一关，要真读代码、真做判断。这次用极简模式，只有两个工具，相当于让 AI“裸奔”做深度分析。

**提示词：**

```
工作区里有一个开源项目（D:\gitee\deepseek-harness，DeepSeek Harness 的源码）。帮我做一份项目分析报告：
1) 这个项目是干嘛的、解决什么问题
2) 整体架构和核心模块有哪些
3) 代码质量和设计思路怎么样
4) 它的优缺点，以及适合什么样的人用
输出成一份结构清晰的分析报告，存成新文件。
```

**结果：** 完全超出预期。极简模式只有两个工具，却产出了一份 222 行的完整分析报告。不是泛泛而谈：项目定位、Cordis 插件树架构、核心包、Turn/Step 运行流、事件溯源会话日志都讲到了，还给出了代码质量评价和“适合谁用”的判断，连“不接受外部 PR”这种细节都挖出来了。

耗时 1 分 24 秒（1 轮对话、11 步工具调用），输入 406K、输出 7.5K token，缓存命中 80%。费用约 1 毛 7（空闲时段）/ 3 毛 4（高峰时段）。

## 任务 4：让 AI 给自己造个插件（创造模式）

前三关都是“让 AI 干活”，这一关玩点不一样的：用创造模式让 AI 给自己造个工具。创造模式能检查系统里当前装了哪些插件、现场试验新插件，是 Harness“一切皆插件”理念的直接体现。

我让它做一个跑任务时能实时看到账户余额的悬浮窗插件——一边干活一边看着钱扣，肉疼感直接拉满。

**提示词：**

```
帮我在界面上做一个「余额悬浮窗」插件：实时显示 DeepSeek 账户剩余金额，跑任务时能看着钱一点点扣。写完先给我审批，没问题再装。
```

**结果：** 插件正常装上，余额悬浮窗显示的数字和账户实际余额完全对得上，装完就能用。

耗时 6 分 48 秒（2 轮对话、15 步工具调用，工具执行 10 分 45 秒），输入 1.2M、输出 44.5K token，缓存命中 89%。费用约 4 毛 5（空闲时段）/ 9 毛（高峰时段）。

# 七、进阶玩法：装完插件才算完整

Harness 主打“一切皆插件”，连操作界面都是插件，所以换皮肤、扩展功能在它这儿特别简单。这里以换皮肤为例，四步走：

**第一步：安装 dsh 命令**（已装的可以忽略）

```bash
npm install -g @deepseek-ai/dsh
```

**第二步：安装 UI 插件**

```bash
dsh plugin --profile web add @linxin666/dsh-web-ui-all@0.1.12
```

**第三步：重启网页生效**

```bash
dsh web
```

**第四步：刷新浏览器**，在设置里选择新皮肤即可。
